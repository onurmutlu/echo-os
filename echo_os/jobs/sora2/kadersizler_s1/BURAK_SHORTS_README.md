## 🚀 Render Commands

### Full Pipeline (Automated)
```bash
./echo_os/jobs/sora2/kadersizler_s1/render_burak_shorts.sh
```

### Manual Steps

#### 1. Render with Sora-2
```bash
python -m echo_os.cli render \
  --job-file echo_os/jobs/sora2/kadersizler_s1/burak_rizik_caba_shorts_job_echoos.json \
  --output-dir renders/shorts/burak_rizik_caba \
  --model sora-2
```

#### 2. Post-Production
```bash
python -m echo_os.post_production \
  --input renders/shorts/burak_rizik_caba/raw \
  --output renders/shorts/burak_rizik_caba/final \
  --config echo_os/jobs/sora2/kadersizler_s1/burak_rizik_caba_shorts_job_echoos.json
```

#### 3. Export for Platforms
```bash
# YouTube Shorts
ffmpeg -i final.mp4 -c:v libx264 -crf 18 -maxrate 10M \
  -c:a aac -b:a 192k burak_rizik_caba_youtube.mp4

# Instagram Reels
ffmpeg -i final.mp4 -c:v libx264 -crf 20 -maxrate 8M \
  -c:a aac -b:a 128k burak_rizik_caba_instagram.mp4

# TikTok
ffmpeg -i final.mp4 -c:v libx264 -crf 22 -maxrate 6M \
  -c:a aac -b:a 128k burak_rizik_caba_tiktok.mp4
```
